# Patitas v0.1 - Motor de Historiales Clínicos

Sistema en JavaScript para gestionar los historiales médicos de mascotas en una clínica veterinaria, permitiendo registrar atenciones y generar reportes de costos y vacunas.

## Cómo ejecutarlo

1. Abre la terminal en la carpeta raíz del proyecto (`patitas-motor`).
2. Ejecuta el reporte principal con Node.js:
   ```bash
   node src/reporte.js
